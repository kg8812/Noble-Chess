# Noble Chess

기획자 2명과 협업하여 제작한 체스 기반 전략 게임입니다.  
체스 규칙과 캐릭터 스킬을 결합하고, 행동을 예약하여 실행하는 시스템을 구현했습니다.

---

## 게임 소개

Noble Chess는 클래식 체스 규칙을 기반으로 하면서,  
각 기물에 고유한 스킬을 추가한 전략 게임입니다.

플레이어는 단순한 이동뿐만 아니라,  
스킬 사용과 행동 예약을 통해 다양한 전략을 구성할 수 있습니다.

팀 프로젝트로 진행되었으며,  
기획과 협업하여 게임의 전체적인 흐름과 시스템을 구현했습니다.

<br/>

---

## 주요 기능

- 체스 기물 이동 및 기본 규칙 구현
- 캐릭터별 고유 스킬 시스템
- 행동을 미리 설정하고 실행하는 예약 시스템
- 턴 기반 게임 진행
- 유효한 이동 범위 계산
- 게임 종료 조건 처리 (체크메이트 등)
- UI를 통한 게임 상태 표시

<br/>

---

## 핵심 시스템

### 체스 + 스킬 결합
기존 체스의 이동 규칙을 유지하면서,  
각 기물에 스킬을 추가하여 전략 선택의 폭을 확장했습니다.

### 행동 예약 시스템
플레이어가 행동을 미리 선택하면,  
정해진 순서에 따라 실행되는 구조를 통해  
턴 기반 게임에 전략적인 깊이를 더했습니다.
